## 📋 整理分类计划

### 第一阶段：清理缓存和临时文件

#### 1.1 删除Python缓存文件
```bash
# 删除所有__pycache__目录
find . -type d -name "__pycache__" -exec rm -rf {} +

# 删除所有.pyc文件
find . -name "*.pyc" -delete

# 删除所有.pyo文件
find . -name "*.pyo" -delete
```

#### 1.2 删除工具缓存
```bash
# 删除MyPy缓存
rm -rf .mypy_cache

# 删除Pytest缓存
rm -rf .pytest_cache

# 删除覆盖率文件
rm -f .coverage
rm -rf htmlcov/
```

#### 1.3 删除构建产物
```bash
# 删除构建目录
rm -rf build/
rm -rf dist/
rm -rf *.egg-info/
```

#### 1.4 删除临时文件
```bash
# 删除日志文件
find . -name "*.log" -delete

# 删除临时文件
find . -name "*.tmp" -delete

# 删除编辑器备份
find . -name "*.bak" -delete
find . -name "*.bak2" -delete
```

### 第二阶段：整理文档文件

#### 2.1 创建审计报告目录
```bash
mkdir -p docs/audit_reports
```

#### 2.2 移动审计报告文件
