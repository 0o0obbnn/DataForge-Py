### 2.1 不安全的JWT密钥配置修复
- **问题**: 在开发模式下使用不安全的默认JWT密钥
- **文件**: `dataforge/config/settings.py`
- **修复方案**:
  1. 修改JWT密钥配置逻辑，强制通过环境变量设置
  2. 添加开发模式的安全警告
  3. 更新启动检查逻辑

**具体修改**:
```python
# 在 dataforge/config/settings.py 中
import os
from pydantic import BaseSettings

class Settings(BaseSettings):
    # 之前使用固定密钥，现在强制从环境变量获取
    JWT_SECRET_KEY: str = os.getenv("JWT_SECRET_KEY", "")
    
    # 添加开发模式警告
    DEVELOPMENT: bool = os.getenv("DEVELOPMENT", "false").lower() == "true"
    
    class Config:
        env_file = ".env"

# 在应用启动时检查密钥
def validate_jwt_secret():
    if not settings.JWT_SECRET_KEY:
        if settings.DEVELOPMENT:
            print("警告: 开发模式下未设置JWT_SECRET_KEY，使用默认值。生产环境必须设置JWT_SECRET_KEY环境变量")
            return "DEV-ONLY-INSECURE-KEY-DO-NOT-USE-IN-PRODUCTION"
        else:
            raise ValueError("生产环境必须设置JWT_SECRET_KEY环境变量")
    return settings.JWT_SECRET_KEY
```

### 2.2 CORS配置加强
- **问题**: 生产环境中可能允许所有来源
- **文件**: `dataforge/config/settings.py`, `dataforge/core/startup_checks.py`
- **修复方案**:
  1. 强制生产环境中必须配置CORS来源
  2. 默认情况下不允许所有来源
  3. 添加CORS配置验证

**具体修改**:
```python
# 在 dataforge/config/settings.py 中
class Settings(BaseSettings):
    # 之前可能允许所有来源，现在强制配置
    ALLOWED_ORIGINS: str = os.getenv("ALLOWED_ORIGINS", "")
    
    @property
    def cors_origins(self):
        if self.ALLOWED_ORIGINS:
            return self.ALLOWED_ORIGINS.split(",")
        elif self.DEVELOPMENT:
            return ["http://localhost:3000", "http://127.0.0.1:3000", "http://localhost:8080"]
        else:
            raise ValueError("生产环境必须设置ALLOWED_ORIGINS环境变量")

# 在 dataforge/core/startup_checks.py 中
def validate_cors_configuration():
    if not settings.DEVELOPMENT and not settings.ALLOWED_ORIGINS:
        raise ValueError("生产环境中必须配置ALLOWED_ORIGINS环境变量")
```

## 3. 中期改进 (P1 - 中优先级)

### 3.1 批量生成效率优化
- **问题**: 在API端点中使用简单循环进行批量生成
- **文件**: `dataforge/api/main.py`
- **修复方案**:
  1. 实现异步批处理功能
  2. 添加批量处理大小限制
  3. 优化内存使用

**具体修改**:
```python
# 在 dataforge/api/main.py 中
import asyncio
from typing import List

async def _execute_async_generation(generator, count: int, **params):
    """
    优化后的异步批量生成函数
    """
    batch_size = int(os.getenv("BATCH_SIZE", 100))  # 可配置的批处理大小
    
    if count <= batch_size:
        # 如果数量小于等于批处理大小，直接处理
        tasks = [generator(**params) for _ in range(count)]
        results = await asyncio.gather(*tasks)
        return results
    else:
        # 分批处理大批量数据
        results = []
        for i in range(0, count, batch_size):
            current_batch_size = min(batch_size, count - i)
            batch_tasks = [generator(**params) for _ in range(current_batch_size)]
            batch_results = await asyncio.gather(*batch_tasks)
            results.extend(batch_results)
            
            # 可选：在批次之间添加小延迟，避免对系统造成过大压力
            if i + batch_size < count:
                await asyncio.sleep(0.01)  # 10毫秒延迟
                
        return results
```

### 3.2 Redis连接池实现
- **问题**: Redis连接是全局实例，可能影响连接复用效率
- **文件**: `dataforge/core/redis_client.py`
- **修复方案**:
  1. 实现Redis连接池
  2. 修改客户端初始化逻辑
  3. 添加连接池配置选项

**具体修改**:
```python
# 在 dataforge/core/redis_client.py 中
import redis
from redis.connection import ConnectionPool

class RedisClient:
    def __init__(self):
        self.host = os.getenv("REDIS_HOST", "localhost")
        self.port = int(os.getenv("REDIS_PORT", 6379))
        self.password = os.getenv("REDIS_PASSWORD", None)
        self.db = int(os.getenv("REDIS_DB", 0))
        self.max_connections = int(os.getenv("REDIS_MAX_CONNECTIONS", 20))  # 连接池大小
        
        # 创建连接池
        self.pool = ConnectionPool(
            host=self.host,
            port=self.port,
            password=self.password,
            db=self.db,
            max_connections=self.max_connections,
            decode_responses=True
        )
        
        # 使用连接池创建客户端
        self.client = redis.Redis(connection_pool=self.pool)
    
    def close(self):
        """关闭连接池"""
        if hasattr(self, 'pool'):
            self.pool.disconnect()
```

# 创建新的验证基类文件: dataforge/generators/validation_base.py
from abc import ABC, abstractmethod
from typing import Any, Dict

class BaseValidator(ABC):
    """通用验证基类"""
    
    @staticmethod
    def validate_required_params(params: Dict[str, Any], required_keys: list) -> bool:
        """验证必需参数"""
        for key in required_keys:
            if key not in params or params[key] is None:
                return False
        return True
    
    @staticmethod
    def validate_param_type(param_value: Any, expected_type: type) -> bool:
        """验证参数类型"""
        return isinstance(param_value, expected_type)
    
    @staticmethod
    def validate_param_range(param_value: int, min_val: int = None, max_val: int = None) -> bool:
        """验证参数范围"""
        if min_val is not None and param_value < min_val:
            return False
        if max_val is not None and param_value > max_val:
            return False
        return True

- **修复方案**:

```python
# 在 dataforge/api/main.py 中
import json
from typing import Dict, Any

def parse_json_params(json_str: str) -> Dict[str, Any]:
    """通用JSON参数解析函数"""
    try:
        params = json.loads(json_str)
        if not isinstance(params, dict):
            raise ValueError("参数必须是JSON对象")
        return params
    except json.JSONDecodeError:
        raise ValueError("无效的JSON格式")
    except Exception as e:
        raise ValueError(f"参数解析错误: {str(e)}")

def validate_params_type(params: Dict[str, Any], expected_types: Dict[str, type]) -> Dict[str, Any]:
    """验证参数类型"""
    validated_params = {}
    for key, expected_type in expected_types.items():
        if key in params:
            if not isinstance(params[key], expected_type):
                raise ValueError(f"参数 {key} 必须是 {expected_type.__name__} 类型")
            validated_params[key] = params[key]
    return validated_params
```
