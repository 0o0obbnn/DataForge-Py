## 技术实现

### 配置加载器模式

所有配置加载器遵循统一的设计模式：

```python
@lru_cache(maxsize=1)
def load_xxx_config(locale: str = "zh_CN") -> dict[str, Any]:
    """加载配置，使用LRU缓存"""
    # 1. 检查缓存
    # 2. 加载YAML文件
    # 3. 验证数据结构
    # 4. Fallback到默认配置（如果失败）
    # 5. 缓存并返回
```

### 关键特性

1. **缓存机制**：使用 `@lru_cache` 确保配置只加载一次
2. **Fallback机制**：配置文件缺失时自动使用硬编码默认值
3. **错误处理**：完善的异常处理和日志记录
4. **向后兼容**：API 保持不变，只改变内部实现
5. **多语言支持**：通过 `locale` 参数支持不同语言环境

## 配置文件维护指南

### 如何修改配置

1. **编辑 YAML 文件**
   ```bash
   # 编辑配置文件
   vim dataforge/resources/occupation_zh.yaml
   ```

2. **验证格式**
   ```python
   import yaml
   with open('dataforge/resources/occupation_zh.yaml') as f:
       yaml.safe_load(f)  # 如果格式错误会抛出异常
   ```

3. **清除缓存（开发时）**
   ```python
   from dataforge.resources.occupation_loader import clear_config_cache
   clear_config_cache()  # 重新加载配置
   ```

### 配置文件格式规范

1. **YAML 格式**：使用 2 空格缩进
2. **编码**：UTF-8
3. **注释**：使用 `#` 添加说明
4. **结构**：顶层键为生成器名称（如 `occupation:`）

### 添加新配置项

1. 在 YAML 文件中添加新数据
2. 在加载器的 `_load_default_config()` 中添加对应的默认值
3. 在生成器的 `_setup()` 中加载新配置项
4. 添加相应的测试用例
