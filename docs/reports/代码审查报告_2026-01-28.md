### 3. ✅ generators/finance/stock.py - 使用不安全的random模块

**问题描述**: 使用`random.choices()`生成股票代码，这不是密码学安全的随机数生成器

**原始代码**:
```python
import random  # TODO: Convert to secrets
# ...
code = "".join(random.choices("ABCDEFGHIJKLMNOPQRSTUVWXYZ", k=length))
```

**修复方案**: 使用`secrets`和`string`模块
```python
import secrets
import string
# ...
code = "".join(secrets.choice(string.ascii_uppercase) for _ in range(length))
```

**状态**: ✅ 已修复并提交

### 4. ✅ config/settings.py - 硬编码不安全的JWT密钥

**问题描述**: 开发模式使用硬编码的字符串作为JWT密钥，存在安全风险

**原始代码**:
```python
return "DEV-ONLY-INSECURE-KEY-DO-NOT-USE-IN-PRODUCTION"
```

**修复方案**: 使用`secrets.token_hex(32)`动态生成安全密钥
```python
import secrets
return secrets.token_hex(32)  # 每次重启都会变化
```

**状态**: ✅ 已修复并提交

### 3. ✅ name.py - 缺少输入验证

**位置**: `generators/basic/name.py:152-163`

**问题描述**: 没有验证`name_type`是否为有效值

**原始代码**:
```python
def generate_single(self, context: GenerationContext | None = None) -> str:
    """生成单个姓名"""
    if self.name_type == "EN":
        return self._generate_english_name()
    elif self.name_type == "CN":
        return self._generate_chinese_name(context)
    else:  # BOTH
        return (
            self._generate_chinese_name(context)
            if random.random() < 0.8
            else self._generate_english_name()
        )
```

**修复方案**: 添加输入验证和使用secrets
```python
def generate_single(self, context: GenerationContext | None = None) -> str:
    """生成单个姓名"""
    valid_name_types = {"CN", "EN", "BOTH"}
    if self.name_type not in valid_name_types:
        logger.warning(f"Invalid name_type: {self.name_type}, using BOTH")
        self.name_type = "BOTH"

    if self.name_type == "EN":
        return self._generate_english_name()
    elif self.name_type == "CN":
        return self._generate_chinese_name(context)
    else:  # BOTH
        return (
            self._generate_chinese_name(context)
            if secrets.randbelow(100) < 80  # 80%概率中文
            else self._generate_english_name()
        )
```

**状态**: ✅ 已修复并提交

### 4. ✅ redis_client.py - 缺少资源释放机制

**位置**: `core/redis_client.py`

**问题描述**: `RedisClient`没有实现上下文管理器

**原始代码**:
```python
class RedisClient:
    """Redis客户端管理类，支持连接池"""

    def __init__(self):
        # ... 创建连接池
        self.sync_client = redis.Redis(connection_pool=self.sync_pool)
        self.async_client = aioredis.Redis(connection_pool=self.async_pool)

    def close(self):
        """关闭连接池"""
        if hasattr(self, "sync_pool"):
            self.sync_pool.disconnect()
        if hasattr(self, "async_pool"):
            self.async_pool.disconnect()
```

**修复方案**: 添加上下文管理器
```python
class RedisClient:
    """Redis客户端管理类，支持连接池和上下文管理"""

    def __init__(self):
        """初始化Redis客户端"""
        # ... 创建连接池
        self.sync_client = redis.Redis(connection_pool=self.sync_pool)
        self.async_client = aioredis.Redis(connection_pool=self.async_pool)

    def __enter__(self):
        """支持上下文管理器"""
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        """上下文管理器退出时关闭连接"""
        self.close()

    def close(self) -> None:
        """关闭连接池"""
        if hasattr(self, "sync_pool"):
            self.sync_pool.disconnect()
        if hasattr(self, "async_pool"):
            self.async_pool.disconnect()
```

**状态**: ✅ 已修复并提交（重构整个类）
