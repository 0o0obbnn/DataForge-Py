## 现有生成器分析

### 生成器分类统计
基于当前代码库分析，DataForge包含以下9个主要类别的数据生成器：

1. **基础生成器 (basic)** - 15个生成器
   - name.py, company_name.py, idcard.py, address.py, occupation.py
   - education.py, age.py, uuid.py, username.py, gender.py
   - license_plate.py, marital_status.py, password.py
   - enhanced_generators.py, extended_profile.py, context_aware.py, name_optimized.py

2. **联系方式生成器 (contact)** - 4个生成器
   - communication.py, email.py, landline.py, phone.py

3. **金融生成器 (finance)** - 9个生成器
   - advanced.py, bank_account.py, bond.py, crypto_generator.py
   - crypto.py, fund.py, future.py, stock.py, streaming.py

4. **身份标识生成器 (identifier)** - 10个生成器
   - drivers_license.py, id.py, lei.py, logistics.py, organization_code.py
   - passport.py, social_insurance.py, uscc.py, visa.py, bankcard.py

5. **网络生成器 (network)** - 10个生成器
   - device_id.py, geo_coordinates.py, http_header.py, ipv4.py, ipv6.py
   - mac_address.py, network.py, session_token.py, timezone.py, url_generator.py

6. **数值生成器 (numeric)** - 4个生成器
   - advanced.py, decimal.py, number.py

7. **文本生成器 (text)** - 9个生成器
   - article.py, chinese.py, long_text.py, lorem.py, multilingual.py
   - paragraph.py, sentence.py, special_chars.py, string.py

8. **高级生成器 (advanced)** - 9个生成器
   - datetime.py, advanced_timestamp.py, enhanced_timestamp.py, json_generator.py
   - media_files.py, trading_calendar.py, user_behavior.py, xml_generator.py, yaml_generator.py
   - sql_injection.py, xss_payload.py

9. **认证生成器 (auth)** - 4个生成器
   - auth_token.py, email_verification.py, session_id.py, sms_verification.py

### 2. 示例内容设计

#### 2.1 基础示例结构
每个生成器的示例应包含：
```python
def example_generator_name():
    """生成器名称示例"""
    print("=== 生成器名称示例 ===")
    
    # 基本用法
    config = GeneratorConfig(
        generator_type="generator_type",
        parameters={...}
    )
    
    generator = default_factory.create_generator(config)
    
    # 单个生成
    single_result = generator.generate()
    print(f"单个生成: {single_result}")
    
    # 批量生成
    batch_results = generator.generate_batch(5)
    print(f"批量生成: {batch_results}")
    
    # 验证功能
    is_valid = generator.validate(single_result)
    print(f"验证结果: {is_valid}")
    
    # 特殊功能（如果有）
    special_info = generator.get_special_info(single_result)
    print(f"特殊信息: {special_info}")
```

#### 2.2 高级示例结构
