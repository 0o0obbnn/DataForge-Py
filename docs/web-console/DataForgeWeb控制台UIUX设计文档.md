## 1. 设计概述

### 1.1 设计目标

- **效率优先**: 核心路径（创建配置→生成数据→下载）操作步骤最小化

- **清晰直观**: 复杂功能通过直观界面呈现，降低学习成本

- **一致性**: 遵循Ant Design设计语言，保持用户体验一致性

- **强大可控**: 为高级用户提供复杂需求表达能力，同时避免新手困惑


### 1.2 设计原则

- **渐进披露**: 常用功能直接展示，高级功能收纳在二次操作中

- **即时反馈**: 所有操作提供清晰、及时的状态反馈

- **可控感**: 用户随时了解当前状态，支持撤销和回退操作

- **容错性**: 提供清晰的错误提示和恢复路径

## 3. 交互设计

### 3.1 核心工作流程

#### 3.1.1 创建并生成数据流程

1. **入口**: 工作台或配置列表页点击"新建配置"

2. **定义结构**:

    - 从左栏拖拽"对象"或"数组"至画布

    - 在画布节点上右键或点击"+"添加字段

    - 拖拽数据类型到字段上或选中字段后选择类型

3. **配置规则**:

    - 选择字段，右栏显示属性配置面板

    - 填写表单项（输入框、下拉选择、开关等）

    - 点击"高级"展开表达式编辑器

4. **预览与生成**:

    - 点击"预览"按钮，下方滑出预览面板

    - 确认无误后点击"生成"按钮

    - 设置生成数量、输出格式等选项

5. **下载结果**: 生成完成后通知提示并提供下载链接


### 3.2 详细交互说明

#### 3.2.1 配置工作室交互细节

- **画布拖拽**: 支持字段、对象的拖拽排序、嵌套，提供视觉引导线

- **右键菜单**: 画布节点右键提供"添加子字段"、"复制"、"删除"等操作

- **键盘快捷键**:

    - `Ctrl/Cmd + S`: 保存配置

    - `Delete`: 删除选中节点

    - `Ctrl/Cmd + Z`: 撤销操作

- **实时保存**: 配置变更后自动保存草稿，显示"已保存"状态提示


#### 3.2.2 状态设计

- **加载状态**: 所有异步操作显示旋转加载指示器

- **空状态**: 画布为空时显示引导插图和"添加字段"按钮

- **错误状态**:

    - 表单错误: 表单项下方红色文字提示

    - 生成错误: 预览区显示详细错误信息和"重试"按钮

    - 网络错误: 全局提示并提供重试选项

- **成功状态**: 操作完成显示成功提示和下一步引导


## 4. 视觉设计

### 4.1 设计系统

#### 4.1.1 设计Token

css

/* 颜色 */
--primary-color: #1677FF;        /* 主色 - Ant Design蓝 */
--success-color: #52C41A;        /* 成功色 */

#### 4.1.2 字体系统

- **主要字体**: `-apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui`

- **代码字体**: `'Monaco', 'Consolas', 'Liberation Mono', monospace`

- **字号阶梯**: 12px, 14px, 16px, 20px, 24px, 30px


#### 4.1.3 间距系统

基于8pt网格系统: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px

### 4.2 组件设计规范

#### 4.2.1 画布节点组件

vue

<template>
  <div :class="['schema-node', { selected, required }]">

      <span class="node-icon"><FieldIcon :type="fieldType" /></span>

#### 4.2.2 属性面板组件

- **布局**: 垂直排列，标签左对齐，控件右对齐

- **分组**: 使用折叠面板对相关参数进行分组

- **高级功能**: 点击"高级"按钮展开代码编辑器区域


#### 4.2.3 预览表格组件

- **布局**: 紧凑型表格，支持横向滚动

- **长文本处理**: 单行截断，hover时显示Tooltip

- **敏感信息**: 默认脱敏显示（如手机号: 139****1234）

## 5. 响应式设计

### 5.1 断点定义

- **桌面端**: >1200px (完整功能)

- **平板端**: 768px - 1200px (主要功能可用)

- **移动端**: <768px (基础查看功能)


### 5.2 适配策略

- **桌面端**: 三栏布局，完整功能

- **平板端**: 左右栏可收起，画布区域为主

- **移动端**: 单列布局，简化操作流程


## 6. 动效设计

### 6.1 微交互动效

- **面板切换**: 300ms缓动过渡

- **拖拽反馈**: 拖拽时的半透明和轮廓效果

- **加载状态**: 旋转指示器+渐显效果


### 6.2 页面过渡

- **路由切换**: 淡入淡出效果，持续时间250ms

- **面板展开**: 从下方滑入，持续时间300ms

## 10. 实施计划

### 10.1 阶段划分

1. **MVP阶段** (2个月): 核心工作流、基础组件、基本交互

2. **v1.1阶段** (1个月): 高级交互、任务管理、性能优化

3. **v1.x阶段** (后续): 高级功能、团队协作、扩展能力


### 10.2 优先级说明

- **P0**: 核心工作流、基础画布交互、动态表单、实时预览

- **P1**: 高级表达式编辑、任务历史、批量操作

- **P2**: 高级画布交互、团队协作、模板市场
