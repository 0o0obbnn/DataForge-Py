DataForge Web Console - 开发执行蓝本
1. 项目基础指令
1.1 技术栈约束

语言: TypeScript

框架: Vue 3 (Composition API)

UI库: Ant Design Vue

状态管理: Pinia

路由: Vue Router 4

构建工具: Vite

代码规范: ESLint + Prettier

测试框架: Vitest + Vue Testing Library

1.2 工程结构约束

执行约束

所有代码必须 严格遵循 UI/UX 设计文档

所有组件必须 基于 Ant Design Vue 二次封装

所有交互必须 覆盖正常/加载/空/错误/成功状态

所有接口调用必须 统一走 api 层

提交代码必须 通过 ESLint + Prettier 自动检查

版本迭代必须 符合阶段优先级 (P0→P1→P2)

# =========================
# 模块：配置管理
# =========================
- ID: F-Config-01
  模块: 配置管理
  功能点: 新建配置
  前端实现:
    - 在配置列表页提供「新建配置」按钮
    - 点击后跳转到配置编辑器页面
    - 编辑器初始化内容为空白模板
  验收标准:
    - 新建配置后生成唯一ID
    - 页面跳转正常
    - 初始配置为空

- ID: F-Config-02
  模块: 配置管理
  功能点: 保存配置
  前端实现:
    - 在编辑器右上角提供「保存」按钮
    - 点击后调用 API: POST /api/v1/configurations
    - 保存成功后提示“保存成功”
  验收标准:
    - 成功保存后 toast 提示
    - 失败时显示错误信息
    - 控制台无报错

- ID: F-Config-03
  模块: 配置管理
  功能点: 配置列表展示
  前端实现:
    - 表格展示配置列表（名称/更新时间/操作按钮）
    - 操作列：编辑、删除
    - 分页组件（Antd Table + Pagination）
  验收标准:
    - 列表加载正确
    - 编辑按钮跳转编辑器
    - 删除时二次确认

# 模块：数据模板编排器
# =========================
- ID: F-Template-01
  模块: 数据模板编排器
  功能点: 左栏组件库
  前端实现:
    - 使用 Vue Draggable Next 渲染字段组件
    - 字段类型：string, integer, boolean, name, phone

  验收标准:

    - 拖拽时有视觉反馈

- ID: F-Template-02
  模块: 数据模板编排器
  功能点: 中栏画布区
  前端实现:
    - 树形结构展示数据结构
    - 支持拖拽排序、右键菜单（添加/删除字段）
  验收标准:
    - 拖拽排序正确
    - 删除节点后画布更新
    - 节点层级关系正确

- ID: F-Template-03
  模块: 数据模板编排器
  功能点: 右栏属性配置
  前端实现:
    - 选中字段时右栏展示属性表单
    - 表单字段来源 API: GET /api/v1/metadata/generators
    - 表单支持输入校验
  验收标准:
    - 修改字段属性实时更新
    - 输入错误即时提示
    - 配置保存后持久化

# =========================
# 模块：实时预览
# =========================
- ID: F-Preview-01
  模块: 实时预览
  功能点: 样本数据展示
  前端实现:
    - 在编辑器底部提供「生成预览」按钮

    - 表格渲染正确
    - JSON视图内容与配置一致
