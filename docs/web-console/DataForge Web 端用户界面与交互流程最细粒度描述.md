### **DataForge Web 端用户界面与交互流程最细粒度描述**

#### **1. 用户管理模块 (User Management Module)**

**1.1 注册界面 (/register)**

- **页面标题 (<h1>)：** "注册 DataForge 账户"
    
    - **默认状态：** 固定显示。
        
- **注册方式切换 (<div role="tablist">)：**
    
    - **“邮箱注册”选项卡 (<button role="tab">)：**
        
        - **文本：** "邮箱注册"
            
        - **默认状态：** 激活选中 (aria-selected="true", 样式高亮)。
            
        - **最小交互：**
            
            - **点击 (onclick)：** 切换到邮箱注册表单，将“手机号注册”选项卡设置为非激活状态。
                
    - **“手机号注册”选项卡 (<button role="tab">)：**
        
        - **文本：** "手机号注册"
            
        - **默认状态：** 非激活 (aria-selected="false", 样式普通)。
            
        - **最小交互：**
            
            - **点击 (onclick)：** 切换到手机号注册表单，将“邮箱注册”选项卡设置为非激活状态。
                
- **邮箱注册表单 (<form id="email-register-form">) - 默认显示：**
    
    - **“邮箱地址”输入框 (<input type="email" id="email" />)：**
        
        - **标签：** "邮箱地址"
            
        - **占位符 (placeholder)：** "请输入您的邮箱"
            
        - **默认状态：** 空，可编辑。
            
        - **约束：** 邮箱格式（通过前端正则校验）。
            
        - **最小交互：**
            
            - **输入 (oninput)：** 实时校验邮箱格式，若不符合则在下方显示红色错误提示（如邮箱格式不正确），同时“获取验证码”按钮可能保持禁用状态。
                
            - **失去焦点 (onblur)：** 触发后端邮箱是否已注册的校验（异步），并显示提示。
                
    - **“获取验证码”按钮 (<button id="get-email-code" />)：**
        
        - **文本：** "获取验证码"
            
        - **默认状态：** 禁用 (disabled="true")，当邮箱输入框内容符合邮箱格式且未被注册时，变为启用状态。
            
        - **最小交互：**
            
            - **点击 (onclick)：**
                
                1. 发送请求到后端获取邮箱验证码。
                    
                2. 按钮文本变为 60s后重发，进入倒计时状态，并再次禁用。
                    
                3. 若发送成功，在输入框下方显示绿色提示（如验证码已发送，请注意查收）。
                    
                4. 若发送失败（如邮箱不存在、请求频繁），显示红色错误提示。
                    
    - **“邮箱验证码”输入框 (<input type="text" id="email-code" />)：**
        
        - **标签：** "邮箱验证码"
            
        - **占位符 (placeholder)：** "请输入验证码"
            
        - **默认状态：** 空，可编辑。
            
        - **约束：** 通常为6位纯数字。
            
        - **最小交互：**
            
            - **输入 (oninput)：** 实时校验长度和字符类型，若不符合显示错误提示。
                
    - **“设置密码”输入框 (<input type="password" id="password" />)：**
        
        - **标签：** "设置密码"
            
        - **占位符 (placeholder)：** "请设置您的登录密码"
            
        - **默认状态：** 空，可编辑。
            
        - **约束：** 最小8位，包含大小写字母、数字、特殊字符（通过前端正则校验）。
            
        - **最小交互：**
            
            - **输入 (oninput)：** 实时更新“密码强度指示器”的状态。
                
    - **密码强度指示器 (<div id="password-strength">)：**
        
        - **文本：** (如弱, 中, 强)
            
        - **默认状态：** 随“设置密码”输入框内容变化，显示对应的文本和颜色（如弱：红色，中：橙色，强：绿色）。
            
    - **“确认密码”输入框 (<input type="password" id="confirm-password" />)：**
        
        - **标签：** "确认密码"
            
        - **占位符 (placeholder)：** "请再次输入密码"
            
        - **默认状态：** 空，可编辑。
            
        - **约束：** 必须与“设置密码”输入框内容一致。
            
        - **最小交互：**
            
            - **输入 (oninput)：** 实时校验与“设置密码”是否一致，若不一致在下方显示红色错误提示（如两次密码不一致）。
                
    - **“用户协议和隐私政策”复选框 (<input type="checkbox" id="agree-terms" />)：**
        
        - **文本：** "我已阅读并同意《用户协议》和《隐私政策》"
            
        - **默认状态：** 未选中。
            
        - **最小交互：**
            
            - **点击 (onclick)：** 切换选中状态。
                
            - **点击《用户协议》链接 (<a>)：** 在新窗口打开用户协议页面。
                
            - **点击《隐私政策》链接 (<a>)：** 在新窗口打开隐私政策页面。
                
    - **“注册”按钮 (<button id="register-button" />)：**
        
        - **文本：** "注册"
            
        - **默认状态：** 禁用 (disabled="true")，当所有必填项校验通过且协议复选框被选中时，变为启用状态。
            
        - **最小交互：**
            
            - **点击 (onclick)：**
                
                1. 执行所有前端表单最终校验。
                    
                2. 发送注册请求到后端。
                    
                3. 按钮进入加载状态（如文本变为注册中...或显示加载动画），并禁用。
                    
                4. 若注册成功，显示成功提示（如注册成功！），并自动跳转到登录成功后的首页。
                    
                5. 若注册失败，显示后端返回的错误提示（如注册失败，请稍后再试），按钮恢复启用状态。
                    
    - **“已有账户？立即登录”链接 (<a>)：**
        
        - **文本：** "已有账户？立即登录"
            
        - **最小交互：**
            
            - **点击 (onclick)：** 跳转到登录页面 (/login)。
                
- **手机号注册表单 (<form id="phone-register-form">) - 默认隐藏，通过Tab切换显示：** (结构与邮箱注册类似，仅更改以下元素)
    
    - **“手机号”输入框 (<input type="tel" id="phone" />)：**
        
        - **标签：** "手机号"
            
        - **占位符 (placeholder)：** "请输入您的手机号"
            
        - **约束：** 中国大陆手机号格式。
            
        - **最小交互：** (同邮箱地址输入框，但校验手机号格式和是否已注册)
            
    - **“获取验证码”按钮 (<button id="get-phone-code" />)：**
        
        - **文本：** "获取验证码"
            
        - **最小交互：** (同邮箱获取验证码按钮，发送短信验证码)
            
    - **“短信验证码”输入框 (<input type="text" id="sms-code" />)：**
        
        - **标签：** "短信验证码"
            
        - **占位符 (placeholder)：** "请输入验证码"
            
        - **约束：** 6位纯数字。
            
        - **最小交互：** (同邮箱验证码输入框)

#### **2. 数据生成工作台 (Data Generation Workbench)**

**2.1 工作台主界面 (/workbench 或 /workbench/{templateId})**

- **顶部全局操作区 (<header>)：**
    
    - **任务名称 (<h1 contenteditable="true">)：** "未命名任务" 或 "模板名称"
        
        - **默认状态：** 可编辑，显示当前任务名称。
            
        - **最小交互：**
            
            - **双击 (ondblclick) 或点击 (onclick)：** 进入编辑状态，显示文本输入框。
                
            - **输入 (oninput)：** 实时更新名称，若有改动则“保存为模板”按钮变为启用状态。
                
            - **失去焦点 (onblur) 或按回车 (onkeydown='Enter')：** 保存名称修改（仅前端状态，实际保存需点击“保存为模板”）。
                
- **左侧栏 (字段库 <aside id="field-library">)：**
    
    - **标题 (<h2>)：** "字段库"
        
    - **搜索框 (<input type="search" placeholder="搜索数据类型..." id="field-search" />)：**
        
        - **默认状态：** 空，可输入。
            
        - **最小交互：**
            
            - **输入 (oninput)：** 实时过滤下方分类列表和数据类型列表，只显示匹配项。
                
    - **分类列表 (<ul id="field-categories">)：** (可折叠/展开的手风琴效果)
        
        - **分类标题 (<li class="category-header">)：** (如“基础信息”)
            
            - **文本：** "基础信息"
                
            - **图标：** (小箭头，指示展开/折叠状态)
                
            - **最小交互：**
                
                - **点击 (onclick)：** 切换该分类的展开/折叠状态，隐藏/显示下属数据类型。
                    
        - **数据类型列表 (<ul class="data-types">)：** (位于分类标题下方)
            
            - **数据类型项 (<li class="data-type-item">)：** (如“姓名”)
