## 设计灵感与组件库建议 - DataForge Web端 (科技感·未来风)

### 1. 风格定位与关键词 (Style Positioning & Keywords)
DataForge作为数据生成工具，其UI/UX应体现高效、智能、专业且具前瞻性的特质。我们将融合现代科技美学与极简主义，营造一个既能沉浸式操作，又能清晰洞察数据的未来工作空间。

-   **关键词:** 现代、科技、未来、沉浸、专业、极简、高效、智能、流畅、数据驱动

### 2. 视觉元素分析 (Visual Element Analysis)

#### 2.1. 色彩策略 (Color Palette)
我们将以深色模式为主要基调，辅以精心挑选的亮色作为交互和视觉焦点，营造科技感和沉浸感，同时保证信息的高效传递。

-   **主色调 (Primary/Base):**
    *   `#1A1A2E` (深空蓝 - 作为背景主色，提供沉稳的科技感)
    *   `#282845` (深邃紫 - 作为卡片、面板背景，增加层次和深度)
-   **辅助色 (Accent/Interactive):**
    *   `#8E5DFF` (未来紫 - 主要交互色，按钮、链接、高亮状态，富有活力和科技感)
    *   `#00E676` (霓虹绿 - 次要交互色，成功提示、部分数据可视化，带来清晰和积极反馈)
    *   `#FF5252` (警告红 - 错误提示、危险操作)
    *   `#FFC107` (提示黄 - 警告、待处理状态)
-   **中性色 (Neutral):**
    *   `#E0E0E0` (亮灰 - 用于主要文本、图标，确保深色背景下的高可读性)
    *   `#B0B0B0` (中灰 - 次要文本、描述性文字)
    *   `#4A4A6D` (暗灰 - 分割线、禁用状态、轻量级背景元素)
-   **色彩情绪与应用场景:**
    *   深色基调营造专注、沉浸的工作氛围。
    *   未来紫和霓虹绿作为关键操作和数据亮色，引导用户注意力，提供清晰状态反馈。
    *   高对比度的亮灰文本确保内容清晰可见。

#### 2.2. 字体选择 (Typography)
选择简洁、现代的无衬线字体，确保在各种屏幕和深色背景下的高可读性。

-   **标题字体:** `Inter Bold` 或 `IBM Plex Sans Bold` (用于页面大标题、模块标题，提供力量感和现代感)
-   **正文字体:** `Inter Regular` 或 `IBM Plex Sans Regular` (用于段落、表单文本、列表项，保持信息清晰、阅读舒适)
-   **代码/数据字体:** `JetBrains Mono` 或 `Roboto Mono` (等宽字体，用于代码块、API示例、数据预览，增强专业感和可读性)
-   **字重与字号建议:**
    *   大标题 (H1): 28-36px Bold
    *   模块标题 (H2): 20-24px Bold
    *   正文: 14-16px Regular
    *   辅助文本/标签: 12-14px Regular
    *   强调重要信息的数字或文本可使用 Medium 或 Semibold 字重。
-   **字体情绪与可读性:** 整体简洁、专业，适应深色背景下的信息展示，提升阅读效率。

#### 2.3. 图标与插画风格 (Iconography & Illustration Style)
图标和插画应与整体科技感风格保持一致，简洁而不失细节。

-   **图标风格:**
    *   **线性图标 (Line Icons)**: 粗细适中，带有圆角或少量锐角，色彩可根据状态切换（非激活时中性色，激活时未来紫/霓虹绿）。可考虑Ant Design Icons的线性版本，并进行局部定制。
    *   **面性图标 (Solid Icons)**: 少量用于非常重要的操作或模块标识，使用与线性图标相同的主题色。
    *   **微图标 (Micro Icons)**: 用于列表项、提示信息，保持极简。
-   **插画风格:**
    *   **抽象几何插画/渐变插画**: 用于空状态页面、引导页、错误页等。色彩使用主色调和辅助色的渐变，带有微妙的光效或模糊效果，强调未来感和空间感。避免具象人物，以抽象图形和线条为主。
    *   **一致性原则:** 所有图标和插画应保持统一的视觉语言、线条粗细、色彩饱和度，并与AntD组件风格协调。

#### 2.4. 空间与布局 (Spacing & Layout)
强调清晰的视觉层级、大面积留白和模块化设计，确保信息易于消化和操作。

-   **栅格系统建议:**
    *   基于Ant Design Vue的24列栅格系统，采用`8px`作为基本间距单元。所有内边距、外边距、组件高度、图标大小等均应是`8px`的倍数。
-   **页面布局模式:**
    *   **两栏/三栏布局**: 如工作台（左侧字段库、中间画布、右侧配置），个人中心（左侧导航、右侧内容）。
    *   **卡片式布局 (Card-based Layout)**: 大量使用AntD的`a-card`组件，形成清晰的模块边界。卡片内部内容留白充足，分隔线清晰但不突兀。
    *   **模块化**: 每个功能区域视为独立模块，通过背景色、阴影或边框区分，便于用户识别和专注。
-   **留白策略:**
    *   **功能区之间**: 采用较大间距和深色背景区隔。
    *   **卡片内部**: 充足的内边距，确保内容不拥挤。
    *   **文本行高**: 适当增加行高，提升阅读舒适度。
    *   **目的**: 减少视觉噪音，引导用户视线，提升界面的呼吸感和未来感。

#### 2.5. 纹理与材质 (Texture & Material)
在深色模式下，通过微妙的纹理和光效，增加界面的质感和深度。

-   **背景:** 整体采用纯色背景，但可以在局部区域（如画布、大的内容容器）引入**极其微弱的暗纹理或噪声，或者微妙的径向渐变**，避免死板的纯黑。
-   **卡片/面板:** 可以通过**轻微的内阴影（inner shadow）或边框光效（subtle glow on hover/active）**来模拟科技感屏幕的质感。边角可采用**4px-8px的圆角**，既有现代感又不失友好。
-   **高亮/焦点**: 焦点元素（如选中卡片、激活输入框）可采用**细致的描边光晕效果**，使用辅助色。

### 3. 核心UI组件库建议 (Core UI Component Library Suggestions)
以下建议将指导如何在Ant Design Vue的基础上，定制和应用核心UI组件，以实现整体风格。

-   **按钮 (Buttons - `a-button`):**
    *   **主按钮 (Primary)**: 背景色为 `未来紫` (`#8E5DFF`) 的渐变（可考虑从左上到右下微弱渐变），文本为白色。悬停时，背景渐变稍亮，出现微妙的发光效果。点击时，有清晰的涟漪或按下反馈。圆角：`4px`。
    *   **次按钮 (Default)**: 透明背景，边框为 `暗灰` (`#4A4A6D`) 或 `未来紫` (`#8E5DFF`)，文本为 `亮灰` (`#E0E0E0`) 或 `未来紫`。悬停时，背景出现 `深邃紫` 或 `未来紫` 的半透明填充。
    *   **文本按钮 (Text Button)**: 文本为 `未来紫`，悬停时底线或文本颜色稍亮。
    *   **禁用状态**: 背景色为 `暗灰`，文本颜色为 `中灰`，无悬停效果。
-   **输入框 (Input Fields - `a-input`, `a-textarea`, `a-input-number`, `a-select`):**
    *   **背景色**: `深邃紫` (`#282845`)，与卡片背景色保持一致，或稍暗。
    *   **边框**: `暗灰` (`#4A4A6D`)。
    *   **聚焦时 (Focus State)**: 边框变为 `未来紫` (`#8E5DFF`)，可带有一圈极细的**发光效果**。
    *   **文本颜色**: `亮灰` (`#E0E0E0`)。
    *   **占位符 (Placeholder)**: `中灰` (`#B0B0B0`)。
    *   **错误状态**: 边框变为 `警告红` (`#FF5252`)，并显示红色错误提示文本。
    *   **下拉选择框 (`a-select`)**: 下拉菜单背景与输入框背景一致，选中项高亮使用 `未来紫`，文本为 `亮灰`。
-   **卡片 (Cards - `a-card`):**
    *   **背景色**: `深邃紫` (`#282845`)。
    *   **圆角**: `8px`。
    *   **投影 (Shadow)**: 少量、扩散范围小的深色阴影 (`box-shadow: 0 2px 8px rgba(0, 0, 0, 0.2)`)，在深色背景下不宜过重。
    *   **边框**: 可选择无边框，或使用 `暗灰` (`#4A4A6D`) 的细边框。
    *   **内容分隔**: 内部元素间使用 `暗灰` 的细分割线。
-   **导航 (Navigation - `a-menu`, `a-tabs`):**
    *   **侧边栏 (`a-menu`)**:
        *   背景色：`深空蓝` (`#1A1A2E`)。
        *   非激活项文本：`中灰` (`#B0B0B0`)。
        *   悬停时：背景出现 `深邃紫` 的半透明填充，文本变为 `亮灰`。
        *   激活选中项：背景色为 `深邃紫`，左侧或顶部有 `未来紫` 的高亮条，文本变为 `亮灰`，图标变为 `未来紫`。
    *   **顶部Tab/选项卡 (`a-tabs`)**:
        *   背景色：`深空蓝`。
        *   非激活Tab文本：`中灰`。
        *   激活选中Tab文本：`亮灰`，下划线或高亮条使用 `未来紫`。
        *   悬停时：文本稍亮。
-   **图表 (Charts - 需要集成第三方图表库如ECharts或AntV G2):**
    *   **风格**: 扁平化设计，色彩使用 `未来紫`、`霓虹绿`、`辅助色` 等，避免过多颜色。
    *   **动画**: 平滑、流畅的过渡动画。
    *   **背景**: 透明或与卡片背景一致。
    *   **网格线**: 极细、半透明的 `暗灰` 网格线。
    *   **提示框**: 简洁的深色背景，亮色文本。
-   **模态框/弹窗 (Modals/Pop-ups - `a-modal`):**
    *   **背景**: `深邃紫` (`#282845`)，圆角 `8px`。
    *   **标题**: `亮灰`，字体 `Inter Bold`。
    *   **内容**: `亮灰` 文本。
    *   **操作按钮**: 遵循按钮的设计规范。
    *   **遮罩层**: 半透明的深色（如 `rgba(0, 0, 0, 0.7)`），增强沉浸感。
-   **微交互 (Micro-interactions):**
    *   **加载动画 (`a-spin`)**: 简洁的线条或几何旋转动画，颜色使用 `未来紫` 或 `霓虹绿`，确保不突兀。
    *   **点赞/收藏反馈**: 细微的缩放、颜色变化或粒子效果。
    *   **拖拽反馈**: 拖拽元素半透明，拖拽目标区域高亮，显示占位符。
    *   **状态切换**: `a-switch` 切换时，滑块颜色从 `暗灰` 变为 `霓虹绿` 或 `未来紫`，并伴有流畅的动画。
